# Network

Goal: establish reliable access, then distinguish link, addressing, routing, DNS and application failures.

## Categories

- [Wireless connection](wireless-connection/README.md): existing Wi-Fi setup and classroom review notes.
- [Network diagnostics](network-diagnostics/README.md): planned measurement and troubleshooting labs.

Prerequisite: board identity and recovery access from [getting started](../getting-started/README.md).

Exit checkpoint: a redacted connection report with interface, IP address, gateway, DNS check and recovery procedure. Never publish passwords or NetworkManager connection files.
